Token Radar ranks every pre-token protocol in a sealed DefiLlama snapshot by the implied value of a future token launch — priced off the market caps of live-token protocols in the same category — and gives each one a concrete farm plan with costs and times. The dashboard renders offline: a filterable board, a detail view with the value breakdown and live-token comparables, and the live-token protocols set aside with the market's own values.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts --input snapshot.json
```
